# 知识库（knowledge/）

技能包的**经验知识层**：存储任务沉淀、评审发现与用户反馈提炼出的最佳实践与正反参考。
规范性知识（规则/规范/宪法）的真值源仍在 `references/` 与 `agents/`（互链不重复）——
两级各司其职：

| 层 | 位置 | 内容 | 级别 |
|---|---|---|---|
| 规范层 | `references/constitution.md`、`references/*.md`、`agents/*.md` | 宪法、协议、红线、门禁、规范 | L1 / L2 |
| 经验层 | `knowledge/` | 正反参考、可选参考、经验教训 | L3 为主 |

写入本目录**只经自进化协议**（`references/self-evolution.md`），
逐条过其第 5 节评审清单后落盘，不接受会话内随手手改。

## 1. 目录与拆分规则

| 文件 | 内容 | 拆分规则 |
|---|---|---|
| `lessons.md` | 任务沉淀与评审发现（正反参考池，按域分组） | 单文件超 300 行或单域超 30 条 → 拆分为 `lessons/<domain>.md`（宪法第 21 条三次法则；拆分动作本身走自进化协议） |

## 2. 条目格式（每条必填）

```markdown
### KB-<域>-<序号> <标题>
- 级别：L1 强制 | L2 推荐 | L3 参考
- 类型：规则 | 最佳实践 | 正参考 | 反参考 | 可选参考
- 来源：任务沉淀（附日期） | 评审发现（附轮次/版本，日期经 README 版本历史可溯不重复维护） | 用户反馈（附原话） | 官方文档（附出处）
- 适用：<域 / 栈 / 角色 / 全包>
- 正文：<一句话结论 + 展开>
- 正例：<做对了的样子>（L3 条目正例/反例至少其一，必填性见协议第 4 节）
- 反例：<踩过的坑 + 后果 + 修正>
```

## 3. 准入、升级与退出

- **准入**：挂来源（无来源进 `lessons.md` 末尾提案池，标"待验证"，不落盘为知识）；
  级别已声明；经自进化协议第 5 节评审清单（正反例完整、单一真值源、引用闭环）。
- **升级**：L3 条目被 ≥3 个不同任务验证有效 → 提升为 L2，并评估合入规范层真值源文件
  （经验升级为规范是纵向进化的主要通道）。
- **退出**：被官方文档/新版本证伪 → 条目标注"已失效 + 依据 + 日期"，不删除（留痕）。
- **变更入口唯一**：本目录所有写入/升级/失效动作只经自进化协议，评审清单通过才生效。

## 4. 与 evals 的关系

经验层条目不直接生成 evals 用例；当条目升级为 L2 或合入规范层时，
自进化协议同步评估是否补对应用例（evals 只增不减，见协议第 6 节）。
