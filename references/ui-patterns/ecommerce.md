# UI 模式：电商商城（ecommerce）

> 站点类型模式之一：由 `agents/ui-ux-designer.md` 站点类型路由加载。
> 本文件只定**类型专属**要求；通用要求（五态、四全局态、4.5:1 对比度、44px 点击区）
> 见 `templates/ui-spec.md`，不重复。

## 1. 适用信号

需求含在线销售实体/虚拟商品：商品列表、商品详情（SKU）、购物车、下单支付、
订单与售后。转化目标是**成单**，设计主线是"找得到 → 信得过 → 买得顺"。

## 2. 设计目标与用户心智

- **可发现性**：品类导航 + 搜索 + 筛选排序三条找货路径全部可用。
- **决策支持**：商品详情页一次给齐"图、价、规格、评价、服务"五要素，不逼用户提问。
- **流程顺畅**：从加购到支付完成步骤最少、每步可回退不丢状态、全程无"惊喜"
  （隐藏运费/强制注册/最后一刻加价）。

## 3. 页面清单（IA 模板）

| 页面 | 必备性 | 核心区块 |
|---|---|---|
| 首页 | 必备 | 品类导航 + 搜索 + 活动楼层 + 推荐楼层；不做企业官网式自述 |
| 品类/搜索结果列表页 | 必备 | 筛选排序栏（含已选条件回显）+ 商品卡网格 + 分页或无限滚动（二选一） |
| 商品详情（商详） | 必备 | 见 §4 商详页 IA |
| 购物车 | 必备 | 商品行（SKU 图/名/单价/数量/小计）+ 优惠明细 + 结算入口 + 失效商品区 |
| 结算页 | 必备 | 地址 + 配送方式 + 支付方式 + 优惠 + 合计；**下单前费用全透明** |
| 支付结果页 | 必备 | 成功态（订单号/入口）/ 失败态（原因 + 重试 + 订单仍保留） |
| 订单列表/详情 | 必备 | 状态流转 + 操作（取消/支付/查看物流/申请售后） |
| 售后 | 必备 | 退换货申请流程与进度 |
| 个人中心 | 必备 | 地址管理、收藏、客服入口 |
| 登录注册 | 必备 | 游客可浏览；下单才要求登录（见 §10） |
| 营销活动页 | 常备 | 优惠券领取、秒杀/拼团规则透明 |

## 4. 商详页 IA（类型核心页）

- 首屏：主图区（多图/视频切换，统一比例不变形）+ 标题/副标题 + 价格区
  （现价/划线价/优惠标签）+ SKU 选择（切换联动价格、库存、主图）+
  数量 + 主 CTA（加购/立即购买）+ 服务保障条（七天退换/正品/发票）。
- 滚动：配送信息（时效/运费）→ 商品详情（图文/参数表）→ 评价区
  （带图优先、可按标签筛选、负面评价不隐藏）→ 推荐。
- 移动端：主 CTA 底部常驻（拇指区），SKU 选择用半屏抽屉。

## 5. 关键交互流与失败分支（下单漏斗）

加购 → 购物车 → 结算 → 支付 → 结果页。每步可返回且**不丢已填状态**。

必画失败分支（缺一即门禁不过）：

- SKU 组合缺货：不可选灰态 + 到货通知入口，不在选完后才报错。
- 库存不足/库存变动：加购或下单时明确提示剩余可购数量。
- 价格变动：下单前后台改价 → 结算页显著提示并要求确认，不静默按新价下单。
- 支付失败/中断：订单保留（明确保留时限），提供重新支付入口。
- 超时未支付：明确倒计时提示，超时后订单取消并告知。

## 6. 类型专属组件

商品卡（图/名/价/标签/售罄态，五态含售罄）、SKU 选择器、价格展示区、
筛选排序栏、优惠券领取组件、评价卡、购物车行编辑、支付方式选择。
所有交互组件五态齐全（通用要求）。

## 7. 视觉与布局基调

- CTA 高对比且全局唯一语义（加购/立即购买视觉区分明确）。
- 商品图统一比例与背景规范，列表加载有占位（骨架/底色），不跳动。
- 移动端底部常驻操作区（商详/购物车），点击区 ≥44px。
- 营销氛围（大促皮肤）不牺牲可读性：正文对比度不因氛围图下降。

## 8. 信任与合规要点

- 价格展示规范：划线价须真实有依据；优惠规则可点开查看完整条款。
- 库存、时效、紧迫感如实：虚假倒计时、假库存、假销量是红线。
- 支付安全提示；退换货政策、隐私政策从结算页可直达。
- 发票说明、客服入口全站可达（时效承诺如实）。

## 9. 度量建议

加购率、结算转化率、购物车放弃率、搜索无结果率、商详页停留与加购比、
SKU 切换率（设计侧只建议埋点位置，不定义指标口径）。

## 10. 反模式（红线）

- 结算前强制注册（游客可浏览、下单时才要求登录，登录后回跳不丢购物车）。
- 隐藏运费到最后一刻；下单流程中插入不可跳过的推荐/问卷。
- SKU 切换不联动价格与库存；购物车改数量后小计不刷新。
- 列表页与商详页价格不一致、评价区隐藏差评。
