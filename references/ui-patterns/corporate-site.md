# UI 模式：企业官网（corporate-site）

> 站点类型模式之一：由 `agents/ui-ux-designer.md` 站点类型路由加载。
> 本文件只定**类型专属**要求；通用要求（五态、四全局态、4.5:1 对比度、44px 点击区）
> 见 `templates/ui-spec.md`，不重复。

## 1. 适用信号

需求主体是"公司"而非"某个产品"：公司介绍、业务/解决方案展示、案例、新闻动态、
招聘、投资者关系；核心转化是**线索留资**（咨询/预约/联系），不是在线下单。

## 2. 设计目标与用户心智

- 访客 10 秒内回答三问：这家公司是谁、做什么、靠不靠谱。
- 目标是建立**信任与专业形象**，首屏克制、留白充分，不堆功能细节。
- 双受众：客户（找服务）+ 求职者/投资者/媒体（找信息），导航必须同时可达。

## 3. 页面清单（IA 模板）

| 页面 | 必备性 | 核心区块 |
|---|---|---|
| 首页 | 必备 | Hero + 核心业务 + 标杆客户 + 数据亮点 + 最新动态 + CTA |
| 关于我们 | 必备 | 公司定位、发展沿革（时间轴）、团队、企业文化 |
| 业务/解决方案 | 必备 | 按行业或能力分组；每项一段价值描述 + 案例入口 |
| 案例中心 | 必备 | 筛选（行业/方案）+ 案例卡（封面、行业标签、客户名、成果指标）+ 案例详情 |
| 新闻/动态 | 必备 | 列表（时间 + 分类）+ 详情 |
| 招聘 | 常备 | 职位列表（部门/地点筛选）+ 职位详情 + 投递入口 |
| 联系我们 | 必备 | 留资表单 + 多渠道（电话/邮箱/地址地图） |
| 投资者关系 | 可选 | 财报、公告、股价（如为上市/拟上市企业） |

一级导航 ≤ 7 项；案例与业务互链（业务页挂案例，案例页回链业务）。

## 4. 首屏公式

品牌主张（一句话说清公司定位）+ 次级说明（一段话，≤60 字）+
主 CTA（联系我们/预约咨询，唯一）+ 辅 CTA（了解业务）+
信任背书条（客户 logo 墙 / 资质数字 / 服务年限）。
首屏不放长段文案、不放自动播放视频音频。

## 5. 关键交互流与失败分支

- **线索留资流**（核心转化，字段最少化：姓名、联系方式、需求描述，≤5 字段）：
  提交成功 → 明确反馈 + 预期响应时限；失败分支：字段校验错误（定位到字段说人话）、
  网络失败（保留已填内容 + 重试）。
- **案例筛选流**：筛选条件即时生效，无结果给"清空筛选"出口，不给死胡同。
- 图文详情页（新闻/案例）必有上一篇/下一篇或返回列表入口，不出现孤页。

## 6. 类型专属组件

Hero 区、客户 logo 墙、案例卡片、数据亮点（数字 + 说明，可选滚动渐入动效）、
公司沿革时间轴、留资表单、多渠道联系块。所有交互组件五态齐全（通用要求）。

## 7. 视觉与布局基调

- 克制、留白多、品牌色主导；图片品质优先，真实业务场景图优于图库摆拍。
- 中英双语站点：导航与标题预留 30% 文本膨胀空间，不在窄容器里硬塞长英文。
- 动效仅限滚动渐入与数字变化，禁止整屏视差堆叠。

## 8. 信任与合规要点

- 页脚常驻：ICP 备案号（境内站点）、版权、隐私政策链接。
- 资质证书、荣誉展示须可提供出处；客户 logo 展示须有授权。
- 留资表单提交前明示隐私政策勾选项（如目标市场有合规要求）。

## 9. 度量建议

线索留资转化率、案例页深度浏览率、联系入口点击率、招聘职位详情到达率
（设计侧只建议埋点位置，不定义指标口径——口径归需求/数据侧）。

## 10. 反模式（红线）

- 首屏做成功能说明书或大段公司自述。
- 自动播放轮播图 > 3 张、自动播放音视频。
- 留资表单超过 5 个字段、必填"公司规模/预算"类推销性字段。
- 案例只有客户名没有成果指标；资质荣誉无出处。
