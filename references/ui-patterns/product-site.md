# UI 模式：产品官网（product-site）

> 站点类型模式之一：由 `agents/ui-ux-designer.md` 站点类型路由加载。
> 本文件只定**类型专属**要求；通用要求（五态、四全局态、4.5:1 对比度、44px 点击区）
> 见 `templates/ui-spec.md`，不重复。

## 1. 适用信号

需求主体是"一个可注册/可下载的产品"：SaaS、工具、App、硬件；
站点目标是**转化漏斗**——了解 → 信任 → 定价 → 注册/下载/预约演示。

## 2. 设计目标与用户心智

- 30 秒内回答："这是什么、解决我什么问题、怎么开始"。
- 说结果不说功能：每个功能块先给场景/收益，再给能力描述。
- 漏斗意识：首页（转化入口唯一化）→ 功能页（建立兴趣）→ 案例/评价（建立信任）
  → 定价页（消除疑虑）→ 注册/下载（零摩擦）。

## 3. 页面清单（IA 模板）

| 页面 | 必备性 | 核心区块 |
|---|---|---|
| 首页 | 必备 | 首屏公式 + 核心特性（3-6 条）+ 产品可视 + 社会证明 + CTA 收尾 |
| 产品/功能页 | 必备 | 按模块或场景组织；每块一图一事，图文左右交替 |
| 定价页 | 必备 | 套餐卡对比 + 差异表 + 计费方式切换（年/月）+ FAQ |
| 客户案例/评价 | 必备 | 案例（客户 + 场景 + 量化结果）+ 评价摘要 |
| 资源中心 | 常备 | 博客 / 帮助文档 / 更新日志（changelog）入口 |
| 下载/注册引导页 | 常备 | 按平台分流（App）/ 按步骤引导（桌面软件）/ 注册表单（SaaS） |
| 关于 | 可选 | 轻量：一句话 + 团队 + 联系方式 |

## 4. 首屏公式

一句话价值主张（说结果，≤15 字）+ 副标题（目标人群 + 核心差异）+
主 CTA（免费试用/下载，**唯一主按钮**）+ 产品可视（截图/动图/≤15s 静音自动播放短视频）+
社会证明（用户数 / 评分 / 客户 logo）。

## 5. 关键交互流与失败分支

- **注册/试用流**（核心转化）：第三方登录优先展示；步骤数最小化（邮箱+密码一步完成，
  验证后置）；失败分支：邮箱已占用（给登录入口）、验证码过期（明确重发路径）、
  密码强度不达标（实时强度反馈，不是提交后报错）。
- **定价选择流**：套餐选择 → 免费套餐直接注册 / 付费套餐进入结账或"联系销售"分流
  （企业版不硬造在线结账）；切换年/月计费时价格联动刷新且不跳动布局。
- **锚点导航**：单页长滚动区（首页）锚点定位准确，滚动时导航高亮同步。

## 6. 类型专属组件

功能展示块（一图一事）、定价卡（推荐档高亮 + "最受欢迎"标签 + 差异对比表）、
FAQ 折叠组、竞品/旧方案对比表（维度自定但须客观可查证）、注册/登录表单、
更新日志时间线。所有交互组件五态齐全（通用要求）。

## 7. 视觉与布局基调

- 产品截图/界面动图即视觉主体，营销插图为辅。
- 动效克制：滚动渐入 + 关键区一次性演示动效，不整页飘动。
- 定价页表格在移动端降级为纵向套餐卡对比，不横向滚动硬塞。

## 8. 信任与合规要点

- 免费试用条款透明：到期行为、是否自动扣费及提醒方式，显著告知。
- 不做虚假紧迫感：假倒计时、假"仅剩 N 个名额"是红线。
- 客户 logo 与评价须有授权与真实出处；数据类主张（"效率提升 x%"）须可溯源。
- 数据安全/合规认证（等保、ISO、SOC 2 等）有则展示、无则不编造。

## 9. 度量建议

注册转化率、定价页到达率与套餐点击分布、试用激活引导完成率、
CTA 点击热区分布（设计侧只建议埋点位置，不定义指标口径）。

## 10. 反模式（红线）

- 首屏主 CTA 多于 2 个（一主一辅是上限）。
- 功能罗列无场景包装；"功能宇宙图"式全景图。
- 定价藏着掖着（"联系销售"作为唯一价格出口，除非企业版）。
- 假倒计时、假库存、购买水军评价。
